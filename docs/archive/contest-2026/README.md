# Contest archive (Oct 2026)

Said & Done started as an entry for the Wispr Flow × Hacker House Goa shortlisting task: build anything entirely by voice, on camera, in three days. Version 0.1.0 was the submission.

These files are kept as a record of how it was planned and recorded. They are not current specs.
